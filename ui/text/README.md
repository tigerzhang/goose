# @openduck/openduck ACP TUI — Deprecated

> [!WARNING]
> **This project is deprecated and no longer maintained.**
>
> The experimental terminal UI (TUI) that lived here, published to npm as
> [`@aaif/goose`](https://www.npmjs.com/package/@aaif/goose) and later
> [`@openduck/openduck`](https://www.npmjs.com/package/@openduck/openduck), is
> no longer being developed. The source has been removed and the npm package has
> been marked as deprecated.
>
> The TUI previously depended on `@aaif/goose-sdk`; that package is now
> `@openduck/sdk`.

## What to use instead

- **CLI** — use the `openduck` command line interface (`crates/openduck-cli`).
  The legacy `goose` binary remains as an alias.
- **Desktop app** — use the OpenDuck desktop application (`ui/desktop`).
- Any ACP based TUI from https://agentclientprotocol.com/get-started/clients#cli-and-tui

All of these options are actively maintained and receive ongoing feature work.
